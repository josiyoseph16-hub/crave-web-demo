CRAVE CAFE & RESTAURANT DEMO
=============================

HOW TO ADD YOUR IMAGES
----------------------

1. Open the "images" folder.
2. Put your restaurant photos inside it.
3. Rename the photos to these exact names:

   banner.jpeg
   chickenwrap.jpeg
   nice.jpeg
   lasagna.jpeg
   spaghetti.jpeg
   enter.jpeg
   Tagliatelle.jpeg
   place2.jpeg
   pp.jpeg
   cream.jpeg

4. Open index.html in Chrome.

IMPORTANT:
The image filename and extension must match the names above.

Example:
images/chicken-wrap.jpg

If your photo is PNG, either rename it to JPG after converting it,
or change the filename in index.html from .jpg to .png.

GITHUB PAGES
------------

Upload:
- index.html
- style.css
- script.js
- images folder

Keep the images folder in the same location as index.html.

This is a demo concept and is not the official website of Crave Cafe & Restaurant.
Use owner-approved photos, branding, menu information and other content for a real client website.
